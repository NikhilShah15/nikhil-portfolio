# Featured Projects

## 🚲 Bike Rental Demand & Usage Analysis

**Tools:** Python | SQL | Tableau

An end-to-end analysis of **10,886 hourly bike rental records** to understand how time, season, temperature, weather and customer type influence rental demand.

### Key Areas

- Hourly rental demand and peak periods
- Seasonal demand patterns
- Temperature and rental demand relationship
- Weather impact on casual customers
- Casual vs registered customer usage
- Operational and customer-focused recommendations
